# 레이아웃 재설계 토론

## 현재 문제점 (스크린샷 기반)
1. 채팅 영역과 입력 영역의 너비가 불일치
2. 사용자 메시지가 우측 정렬이 아닌 중앙에 위치
3. `--scale` 비율 시스템이 복잡하고 조정 어려움
4. 요소들의 정렬이 전체적으로 엉망

---

## 민수 (사용자 심리 전문가)

### 분석
사용자가 "씨발"이라고 할 정도로 좌절한 이유:
- **예측 불가능성**: 한 곳 수정하면 다른 곳이 깨짐
- **시각적 불협화음**: 정렬 안 맞으면 "뭔가 잘못됐다" 느낌
- **GPT와 비교**: GPT는 단순하고 일관적인데 우리는 복잡함

### 제안
**비율 시스템 완전 제거**. 사용자는 "동적 비율"을 원한 게 아님. 그냥 "깔끔하게 정렬된 화면"을 원함.

---

## 수진 (디자인 효과 전문가)

### 분석
GPT 레이아웃의 핵심:
```
┌─────────────────────────────────────┐
│           [헤더 전체 너비]            │
├─────────────────────────────────────┤
│                                     │
│     ┌─────────────────────┐         │
│     │    채팅 영역 800px   │ ← 중앙  │
│     │   (좌우 여백 동일)    │         │
│     └─────────────────────┘         │
│                                     │
│     ┌─────────────────────┐         │
│     │    입력 영역 800px   │ ← 동일  │
│     └─────────────────────┘         │
│                                     │
└─────────────────────────────────────┘
```

### 문제 원인
현재 CSS에서:
- `chat-messages`와 `chat-input-area`가 같은 max-width를 쓰지만
- 부모 컨테이너 구조가 다름
- padding, margin 계산이 불일치

### 제안
**단순한 컨테이너 구조**:
```css
.chat-container {
  max-width: 800px;
  margin: 0 auto;
  padding: 0 24px;
}
```
채팅과 입력 모두 이 컨테이너 안에서 `width: 100%`로 동작.

---

## 동현 (서비스 철학 전문가)

### 분석
비율 시스템(`--scale`)을 도입한 이유:
- "글씨 크기 바꾸면 전체 비율도 자동 조정"

하지만 실제로:
- 접근성 요구사항이 아니면 필요 없음
- 복잡도만 증가
- 디버깅 어려움

### 제안
**YAGNI 원칙** - 필요할 때 추가해도 늦지 않음.
지금은 **고정 픽셀값**으로 단순하게:
- 폰트: 16px
- 간격: 8px, 16px, 24px, 32px
- 너비: 800px

---

## 지은 (통합 종합)

### 최종 결론

**1단계: 비율 시스템 제거**
```css
/* 제거할 것 */
--scale: 1;
--font-xs: calc(12px * var(--scale));
/* ... 모든 calc() 기반 변수 */

/* 단순화 */
--font-xs: 12px;
--font-sm: 14px;
--font-base: 16px;
--spacing-sm: 8px;
--spacing-md: 16px;
--spacing-lg: 24px;
```

**2단계: 레이아웃 단순화**
```css
/* 채팅 + 입력 공통 컨테이너 */
.chat-main {
  max-width: 800px;
  margin: 0 auto;
  padding: 0 24px;
}

.chat-messages {
  width: 100%;
  /* max-width 제거 - 부모가 관리 */
}

.chat-input-area {
  width: 100%;
  /* max-width 제거 - 부모가 관리 */
}
```

**3단계: 메시지 정렬 확인**
```css
/* 사용자 메시지 - 우측 정렬 */
.message.user-message {
  display: flex;
  justify-content: flex-end;
}

/* AI 메시지 - 좌측 정렬, 전체 너비 */
.message.ai-message {
  display: block;
  width: 100%;
}
```
