# UX 토론 결과: 사이드패널 및 설정 UI 개선

> 토론일: 2026-02-03
> 참여자: 민수(사용자 심리), 수진(시각 디자인), 동현(서비스 철학), 지은(통합 종합)
> 주제: GPT 스타일 사이드패널 도입 여부 및 설정/계정 UI 개선

## 1. 사용자 피드백 요약

| 피드백 | 실제 문제 | 원인 |
|--------|----------|------|
| "AI가 만든 프로젝트 같다" | 과도한 대칭, 인간미 없음 | "나"의 부재, 기계적 정돈 |
| "뭔가 답답하다" | 탈출구 없음, 피드백 부족 | 계정 영역 없음, hover 피드백 약함 |
| "설정이 이상한데 있다" | 설정이 없음 | 미구현 |

## 2. 이미지 분석 결과

### 2-1. 진입점 비교 (이미지 1)

| 요소 | AI 생각 작업공간 | ChatGPT |
|------|------------------|---------|
| 헤더 | 로고 + ⚙️ 아이콘 | 로고 + Plus + 메모리 + 👤 |
| 네비게이션 | 상단 탭 + 좌우 엣지 독 | 좌측 사이드패널 (토글) |
| 계정 | ❌ 없음 | 좌하단 + 우상단 |
| 시각적 무게 | 좌우 대칭 | 좌측에 무게 |

### 2-2. 사이드패널 구조 (이미지 2)

**ChatGPT 사이드패널:**
```
┌─────────────────────┐
│ ✏️ 새 채팅    ⇧⌘O   │  ← 핵심 액션
│ 🔍 채팅 검색   ⌘K   │
│ 🖼️ 이미지           │  ← 도구
│ ⊞ 앱               │
│ ◎ Codex            │
├─────────────────────┤
│ GPT >              │  ← 탐색
│ 프로젝트 >          │
│ 내 채팅 >          │
├─────────────────────┤
│ 👤 대기 김  [업그레이드]│  ← 계정 (고정)
└─────────────────────┘
```

### 2-3. 계정 드롭다운 (이미지 5-7)

**ChatGPT 계정 메뉴 순서:**
1. 사용자 이름 + ID
2. 플랜 업그레이드
3. 개인 맞춤 설정
4. 설정
5. 도움말
6. 로그아웃

### 2-4. 그룹 채팅 vs 페르소나 (이미지 8-9)

| 요소 | AI 생각 작업공간 | ChatGPT 그룹 채팅 |
|------|------------------|-------------------|
| 참여자 | AI 페르소나 | 실제 사람들 + AI |
| AI 호출 | 자동 응답 | @ChatGPT 명시적 호출 |
| 톤 | 보고서 ("관점에서 분석") | 대화체 ("오 좋네") |
| 목적 | 사고 확장 | 협업 |

## 3. 핵심 분석 (페르소나별)

### 민수 (사용자 심리)
- **"나"의 부재**: 계정/프로필이 없어 소속감 없음
- **탈출구 없음**: 설정/로그아웃 경로 불명확 → 갇힌 느낌
- **대화 대상 불명확**: 입력창에 누구에게 말하는지 안 보임

### 수진 (시각 디자인)
- **과도한 대칭**: 좌우 엣지 독 균형 → 기계적
- **시각적 무게 없음**: 시선 유도 포인트 부재
- **Progressive Disclosure 부족**: hover 피드백 약함

### 동현 (서비스 철학)
- **정체성 숨김**: "트리 구조 대화"가 한눈에 안 보임
- **딱딱한 톤**: 보고서 스타일 → AI 느낌 강화
- **차별점 불명확**: GPT와 뭐가 다른지 모름

## 6. 이모지 → 에셋 전환 계획

### 핵심 발견

**"AI가 만든 것 같다"의 주요 원인 = 이모지 남발**

| 문제 | 설명 |
|------|------|
| 통일성 없음 | 🎯📊⚛️🌿🏢📧 - 스타일이 제각각 |
| 플랫폼 의존 | OS마다 이모지 디자인 다름 |
| 프로 느낌 없음 | "급하게 만든 프로토타입" 느낌 |
| 브랜드 없음 | 우리만의 시각 언어 부재 |

### 원칙

| 원칙 | 설명 |
|------|------|
| **이모지 전면 제거** | 프로토타입 느낌 제거 |
| **통일된 아이콘 시스템** | 아이콘 라이브러리 or 커스텀 |
| **최소한의 아이콘** | 필요한 곳에만 사용 |

### 위치별 처리

| 위치 | 현재 | 개선 |
|------|------|------|
| **탭** | 🎯📊⚛️ 이모지 | 텍스트만 |
| **콘텐츠 항목** | 🏢📧 이모지 | 텍스트만 |
| **액션 버튼** | 🌿 이모지 | 텍스트만 또는 → 화살표 |
| **참여 알림** | 🐢📊 이모지 | 페르소나 아바타 (커스텀) |
| **엣지 독** | 🌳💡 이모지 | 아이콘 라이브러리 (Lucide) |
| **페르소나** | 📊 이모지 | 직군별 커스텀 아바타 |

### 개선 예시

**탭:**
```
[AS-IS]  🎯 마케팅 전략 기획 │ 📊 시장 보고서 분석
[TO-BE]  마케팅 전략 기획 │ 시장 보고서 분석
```

**버튼:**
```
[AS-IS]  🌿 인스타그램 전략 탐색
[TO-BE]  인스타그램 전략 →
```

**페르소나:**
```
[AS-IS]  📊 데이터 분석가
[TO-BE]  [■] 데이터 분석가  ← 커스텀 아바타
```

### 에셋 제작 필요 목록

| 에셋 | 용도 | 우선순위 |
|------|------|----------|
| 페르소나 아바타 세트 | 직군별 구분 | 높음 |
| 엣지 독 아이콘 | 생각 트리, 관점 도구 | 높음 |
| 로고 | 헤더 | 중간 |
| 액션 아이콘 | 버튼, 메뉴 | 낮음 (라이브러리 사용)

### 7-4. 추천: Lucide ⭐

**선정 이유:**
- 깔끔하고 모던한 스타일
- React/Vue/Svelte 공식 지원
- Tree-shaking (번들 최적화)

- 무료

**설치:**
```bash
npm install lucide-react
```

**사용:**
```jsx
import { TreePine, Lightbulb, Settings, User } from 'lucide-react'
```

| 설정 | `<Settings />` | `<Gear />` |
| 계정 | `<User />` | `<User />` |

### 7-6. 실무 규칙

**1. 한 프로젝트에 하나의 라이브러리만**
```
❌ Lucide + Heroicons + Feather 혼용
✅ Lucide만 사용
```

**2. 아이콘 사이즈 통일**
```css
--icon-sm: 16px;
--icon-md: 20px;
--icon-lg: 24px;
```

**3. stroke-width 통일**
```jsx
// Lucide 기본값 2, 얇게 하려면
<Settings strokeWidth={1.5} />
```

## 8. 작업공간 관리 구조

### 8-1. 문제 정의

**현재 개념:**
```
작업공간 (생각 정리 공간)
   └── 트리맵 (여러 대화 분기)
         ├── 노드 1
         ├── 노드 2
         └── 노드 3 → 분기 → 노드 3-1, 3-2...
```

**문제:**
- 작업공간이 여러 개면 → 어디서 목록을 볼 것인가?
- GPT는 사이드바에 "프로젝트", "내 채팅" 목록이 있음
- 우리는 좌측에 이미 트리맵이 있음

**딜레마:**
- 사이드바 추가 → 트리맵과 충돌, 인지 과부하
- 사이드바 없음 → 작업공간 목록 볼 곳 없음

### 8-2. 개념 매핑

| 개념 | GPT | 우리 서비스 |
|------|-----|-------------|
| 최상위 | 프로젝트 (폴더) | - (추후 검토) |
| 중간 | 채팅 (대화) | **작업공간** |
| 최하위 | 메시지 | **노드 (트리 분기)** |

**결론:** GPT 채팅 ≈ 우리 작업공간

### 8-3. 검토한 옵션들

**옵션 A: 탭 확장** - 기각
```
🧠 AI 생각 │ 탭1 │ 탭2 │ 탭3 │ +

문제: 탭 많아지면 복잡, 검색 불가
```

**옵션 B: 트리맵 영역 확장** - 기각
```
좌측에 작업공간 목록 + 트리맵 동시 표시

문제: 좌측이 너무 복잡해짐
```

**옵션 C: 홈 화면 분리** - 부분 채택
```
홈 = 작업공간 목록
작업공간 내부 = 트리 + 대화

문제: 작업공간 전환에 2클릭 필요
```

### 8-4. 채택: 드롭다운 + 홈 화면 하이브리드

**GPT 패턴 활용:**
```
[GPT]
┌─────────────────┐
│ ChatGPT ∨       │  ← 모델 선택
└─────────────────┘

[우리 서비스]
┌─────────────────────────┐
│ 마케팅 전략 ∨           │  ← 작업공간 선택
└─────────────────────────┘
```

**1. 홈 화면 (작업공간 목록)**
```
┌────────────────────────────────────────────────────────┐
│ 🧠 AI 생각 작업공간                       ⚙️    [DK]  │
├────────────────────────────────────────────────────────┤
│                                                        │
│   🔍 작업공간 검색...                                 │
│                                                        │
│   + 새 작업공간 만들기                                │
│                                                        │
│   ┌──────────────────────────────────────────────┐    │
│   │ 📁 마케팅 전략                  2시간 전     │    │
│   │    └ 3개 분기, 12개 노드                     │    │
│   ├──────────────────────────────────────────────┤    │
│   │ 📁 React 학습                    1일 전      │    │
│   │    └ 5개 분기, 28개 노드                     │    │
│   └──────────────────────────────────────────────┘    │
│                                                        │
└────────────────────────────────────────────────────────┘
```

**2. 작업공간 내부 (대화 화면)**
```
┌────────────────────────────────────────────────────────┐
│ 🧠 [마케팅 전략 ∨]                       ⚙️    [DK]  │
├────────────────────────────────────────────────────────┤
│      │                                          │      │
│  🌳  │              대화                        │  💡  │
│ 트리 │                                          │ 도구 │
│      │                                          │      │
├────────────────────────────────────────────────────────┤
│  [입력창...]                                    [전송] │
└────────────────────────────────────────────────────────┘
```

**3. 작업공간 드롭다운**
```
[마케팅 전략 ∨] 클릭 시:

┌─────────────────────────┐
│ 🔍 검색...              │
├─────────────────────────┤
│ 📁 마케팅 전략  ●       │  ← 현재 작업공간
│ 📁 React 학습           │
│ 📁 신규 기획            │
├─────────────────────────┤
│ + 새 작업공간           │
│ 🏠 모든 작업공간 보기   │
└─────────────────────────┘
```

### 8-5. 기각된 방식

| 방식 | 기각 이유 |
|------|----------|
| **탭 시스템** | 탭 많아지면 복잡, 검색 불가, 화면 공간 낭비 |
| **좌측 사이드바** | 트리맵과 충돌, 인지 과부하, 정체성 희석 |

### 8-6. 장점

| 장점 | 설명 |
|------|------|
| 탭 없이 깔끔 | 헤더가 단순해짐 |
| 무한 작업공간 지원 | 드롭다운 + 검색으로 해결 |
| 1클릭 전환 | 드롭다운에서 바로 선택 |
| GPT 패턴 활용 | 학습 비용 낮음 |
| 트리맵 유지 | 우리 정체성 보존 |
