# AI 생각 작업공간 - 디자인 분석 문서

## 개요

**비교 대상:**
- **A**: GPT, Claude, Gemini (현대 AI 챗봇 레퍼런스)
- **B**: AI 생각 작업공간 데모 (현재 구현)

**분석 키워드:** 1:1 대화 vs 다중 페르소나, 초대 기반 전문가

**프로그램 특성 이해:**
- "생각을 정리해주는 제2의 뇌"
- 복잡한 사고를 구조화하는 도구
- **1:1 대화 + 필요시 전문가 토론** 두 모드 지원

## 1. 대화 UI 디자인 원칙 (GPT 스타일)

### GPT/Claude 레이아웃 분석

```
┌─────────────────────────────────────────────────────────────┐
│ 헤더 (고정)                                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    [사용자 메시지]                          │  ← 오른쪽 버블
│                                                             │
│ 🤖 AI 응답                                                  │  ← 전체 너비
│    내용이 길어도 문서처럼 읽을 수 있음                       │     블록 스타일
│    코드 블록, 리스트 등 구조화된 콘텐츠                      │
│                                                             │
│    [📋 복사] [👍] [🌿 분기] [🎭 전문가에게 물어보기]        │  ← 액션 버튼
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ 🤖 AI와 대화 중                                             │  ← 컨텍스트 바
├─────────────────────────────────────────────────────────────┤
│ 입력창 (고정)                                               │
└─────────────────────────────────────────────────────────────┘
                                                          │ 스크롤
                                                          ▼ (우측)
```

**특징:**
| 요소 | 분석 |
|------|------|
| 사용자 메시지 | **오른쪽 정렬 버블** - 대화 참여자 구분 |
| AI 응답 | **전체 너비 블록** - 문서처럼 읽기 |
| 아바타 | AI만 좌측 아이콘 (🤖) |
| 액션 버튼 | 응답 하단에 호버 시 표시 |
| 스크롤바 | **chat-area 전체 우측** (GPT 스타일) |

### 현재 구현된 레이아웃

```
┌────────────────────────────────────────────────────────────────────┐
│ 헤더 + 탭 바                                                       │
├────────┬──────────────────────────────────────────────┬────────────┤
│        │                                              │            │
│ 🌳     │                 채팅 영역                     │     💡    │  ← 엣지 독
│ 트리   │         (GPT 스타일 메시지)                   │   관점    │
│        │                                              │   도구    │
│ (엣지) │                                              │  (엣지)   │
│        │                                              │            │
│        ├──────────────────────────────────────────────┤            │
│        │ 컨텍스트 바 (현재 모드 표시)                   │            │
│        ├──────────────────────────────────────────────┤            │
│        │ 입력창                                        │            │
└────────┴──────────────────────────────────────────────┴────────────┘
```

**구현 상태:**
| 요소 | 상태 |
|------|------|
| 사용자 메시지 | ✅ 오른쪽 정렬 버블 |
| AI 응답 | ✅ 전체 너비 블록 + 액션 버튼 |
| 컨텍스트 바 | ✅ 현재 모드 표시 |
| 스크롤바 | ✅ chat-area 우측 (GPT 스타일) |
| 엣지 독 | ✅ 좌우 측면 배치 |

## 2. 두 가지 대화 모드

### 2-1. Standard 모드 (1:1 대화)

**사용 시점:** 기본 상태, AI와 단독 대화

```
                                        [사용자 메시지]
                                        오른쪽 정렬 버블

🤖 AI 응답
   전체 너비 블록
   구조화된 콘텐츠

   [📋 복사] [👍] [🌿 분기] [🎭 전문가에게 물어보기]
```

**특징:**
- GPT/Claude와 동일한 경험
- "🎭 전문가에게 물어보기" 버튼으로 페르소나 모드 진입 가능

### 2-2. Persona 모드 (전문가 토론)

**사용 시점:** 사용자가 전문가를 "초대"한 후

```
                                        [사용자 메시지]
                                        오른쪽 정렬 버블

    🎯 마케터
    ┌─────────────────────────────────────────┐
    │ 마케팅 관점에서의 분석...                │  ← 색상 좌측바
    │ [📋 복사] [🌿 이 의견으로 분기]          │
    └─────────────────────────────────────────┘

    📊 분석가
    ┌─────────────────────────────────────────┐
    │ 데이터 기반 분석...                      │
    └─────────────────────────────────────────┘
```

**특징:**
- 각 전문가별 **아이콘 + 이름 태그 + 고유 색상**
- 말풍선 좌측에 색상 바로 구분
- 사용자가 초대한 전문가만 응답

## 3. 핵심 원칙: 초대 기반 전문가 시스템

### 기존 문제점

> "패널을 열었더니 전문가가 이미 말하고 있다"
> → 사용자 혼란: "나는 요청 안 했는데?"

### 해결: 초대 기반 원칙

```
"페르소나는 사용자가 명시적으로 초대한 후에만 존재한다"
```

| 원칙 | 적용 |
|------|------|
| **초대 전** | 전문가 목록만 표시, 의견 없음 |
| **초대 후** | 채팅에 시스템 메시지 + 전문가 응답 시작 |
| **대화 공간** | **항상 1개** (채팅 영역만) |
| **패널 역할** | 전문가 관리 (초대/해제), 대화 공간 아님 |

### 패널 UI

```
🎭 조언자
─────────────────────
아직 초대된 전문가가 없습니다

[+ 전문가 초대하기]

추천 전문가:
┌─────────────────────────────────┐
│ 🎯 마케터           [초대]     │
│    마케팅 관점 분석             │
├─────────────────────────────────┤
│ 📊 분석가           [초대]     │
│    데이터 기반 분석             │
└─────────────────────────────────┘
```

## 4. 엣지 독 시스템

### v0 → v3 전환 히스토리

| 버전 | 시도 | 문제 | 결과 |
|------|------|------|------|
| v0 | 하단 fixed 토글바 | 전송 버튼 가림 (Critical) | ❌ |
| v1 | 인라인 (입력 위) | 박스감 상실 | ❌ |
| v2 | 헤더 우측 통합 | 정체 불명 | ❌ |
| **v3** | **엣지 독** | 숨기되 보이게 + 행동 분류 | ✅ |

### 엣지 독 구조

```
┌──────┐                                              ┌──────┐
│ 🌳   │   ←── 좌측 독                 우측 독 ──→   │ 💡   │
│ 트리 │       (구조/불안)             (확장/호기심)   │ 관점 │
│      │                                              │ 도구 │
│      │                                              │ ┌──┐ │
│      │                                              │ │🎭│ │ ← 2-tap 메뉴
│      │                                              │ │📄│ │
│      │                                              │ └──┘ │
└──────┘                                              └──────┘
```

**동작:**
- 좌측 독 클릭 → 사이드바(트리) 토글
- 우측 독 클릭 → 미니 메뉴 열림 → 항목 클릭 → 패널 열림
- 패널 열리면 독 숨김

## 5. 컨텍스트 바 + 시스템 메시지

### 컨텍스트 바

현재 대화 상태를 항상 표시:

```
[Standard 모드]   🤖 AI와 대화 중
[Persona 모드]    🎭 마케터, 분석가와 토론 중  [🤖 1:1 전환]
```

### 시스템 메시지

모드 전환 시 채팅에 알림:

```
─────────── 🎭 마케터, 분석가가 참여했습니다 ───────────

─────────── 🤖 1:1 대화로 돌아갑니다 ───────────
```

## 8. 결론

### 핵심 변화

| Before | After |
|--------|-------|
| 3단 고정 레이아웃 | GPT 스타일 + 필요시 패널 |
| 하단 토글바 | **엣지 독** (좌우 측면) |
| 전문가 자동 등장 | **초대 기반** |
| 패널 = 대화 공간 | **패널 = 관리 공간** |
| 말풍선 통일 | **모드별 다른 스타일** |

### 설계 원칙

> 1. **페르소나는 초대 후에만 존재**
> 2. **대화 공간은 항상 1개**
> 3. **상태 전환 시 시스템 메시지**
> 4. **컨텍스트 바로 현재 상태 항시 표시**
