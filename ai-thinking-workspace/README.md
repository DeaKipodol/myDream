# AI 생각 작업공간 - 인터랙티브 데모

> 투자자 피칭 PPT에서 시연한 "AI 생각 작업공간" 컨셉을 실제 작동하는 웹페이지로 구현한 프로토타입

## 핵심 기능

### 1. GPT 스타일 1:1 대화
- 사용자 메시지: 오른쪽 정렬 버블
- AI 응답: 좌측 아이콘 + 전체 너비 블록
- 액션 버튼: 복사, 좋아요, 분기, 전문가에게 물어보기

### 2. 페르소나 모드 (전문가 토론)
- 전문가 초대 기반 시스템
- 전문가별 색상 구분 말풍선
- 패널 ↔ 채팅 양방향 동기화

### 3. 컨텍스트 바 + 시스템 메시지
- 현재 대화 모드 표시
- 모드 전환 알림
- 전문가 참여/퇴장 알림

### 4. 엣지 독 시스템
- 좌측: 트리 사이드바 토글
- 우측: 관점 도구 메뉴 (조언자, 문서)

## 빠른 시작

### 설치 & 실행

```bash
# 프로젝트 디렉토리로 이동
cd ai-thinking-workspace

# 로컬 서버 실행
python3 -m http.server 3000

# 브라우저 열기
http://localhost:3000
```

### 기능 테스트

```
1. 1:1 대화 테스트
   → 메시지 입력 → 사용자(오른쪽) + AI(좌측 블록)

2. 전문가 초대 (방법 1)
   → AI 응답 하단 "🎭 전문가에게 물어보기" 클릭
   → 전문가 선택 → 페르소나 모드 전환

3. 전문가 초대 (방법 2)
   → 우측 엣지 독 → 조언자 패널 → [초대] 클릭

4. 1:1 복귀
   → 컨텍스트 바 "🤖 1:1 전환" 클릭
```

## 두 가지 대화 모드

### Standard 모드 (기본)

```
                                        [사용자 메시지]
                                        오른쪽 정렬 버블

🤖 AI 응답
   전체 너비 블록
   구조화된 콘텐츠

   [📋 복사] [👍] [🌿 분기] [🎭 전문가에게 물어보기]
```

### Persona 모드 (전문가 초대 후)

```
                                        [사용자 메시지]

    🎯 마케터
    ┌─────────────────────────────────────────┐
    │ 마케팅 관점에서의 분석...                │
    └─────────────────────────────────────────┘

    📊 분석가
    ┌─────────────────────────────────────────┐
    │ 데이터 기반 분석...                      │
    └─────────────────────────────────────────┘
```

## 주요 기술

| 기술 | 용도 |
|------|------|
| **Vanilla JS** | 클래스 기반 모듈화 (ChatManager, PanelManager) |
| **CSS Variables** | 색상 팔레트, 전문가별 색상 |
| **Flexbox** | 레이아웃, 엣지 독 |
| **Event Delegation** | 동적 요소 이벤트 처리 |

---

## 핵심 설계 원칙

1. **페르소나는 초대 후에만 존재** - 사용자가 부르지 않으면 등장하지 않음
2. **대화 공간은 항상 1개** - 채팅 영역만 대화 공간, 패널은 관리용
3. **상태 전환 시 시스템 메시지** - 사용자가 맥락을 놓치지 않도록
4. **컨텍스트 바로 현재 상태 항시 표시** - 지금 누구와 대화 중인지 명확히
