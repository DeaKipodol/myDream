# 대화 UI 리디자인 - 최종 결정 문서

> 작성일: 2026-02-03
> 4인 UX 토론 (3라운드) 결과

---

## 1. 배경 및 문제 정의

### 현재 상태
- 모든 메시지가 동일한 좌측 정렬 레이아웃 (아바타 + 버블)
- 사용자/AI 시각적 구분이 약함
- 1:1 대화인데 채팅앱처럼 보이는 문제
- 우측 패널(조언자)과 채팅 영역의 역할 혼동 가능성

### 변경 동기
- GPT, Gemini 등 주요 AI 서비스는 1:1 대화에서 말풍선을 사용하지 않음
- 말풍선은 1:다(다중 참여자) 대화에 적합한 UI
- 우리 앱에는 다중 페르소나 기능이 있으므로, 두 모드를 구분해야 함

## 2. 토론 과정에서 나온 주요 고민

### 2-1. 1:1 대화 레이아웃

**고민**: AI 응답을 어떻게 표현할 것인가?

- 말풍선 → AI 응답이 길고 구조화되어 있어서 말풍선에 넣으면 읽기 어려움
- 전체 너비 블록 → GPT/Gemini가 검증한 패턴, 문서처럼 읽을 수 있음

**결론**: 사용자는 AI 응답을 "대화"가 아니라 "답변 문서"로 인식함. 전체 너비 블록이 적합.

### 2-2. 모드 전환 방식

**고민**: 1:1 ↔ 페르소나 전환을 어떻게 할 것인가?

3가지 옵션 검토:
- 옵션 A: 입력창 위에 칩 버튼 `[🤖 1:1]` `[🎭 토론]`
- 옵션 B: 입력창 좌측 아이콘 토글
- 옵션 C: 패널 열면 자동 전환

**문제점 분석**:
- 옵션 A, B: 사용자가 "모드"를 의식해야 함 → 인지 부하
- 옵션 C: 패널을 참고용으로만 열고 싶을 때 강제 전환됨

**최종 결론**: 3가지를 조합한 **하이브리드 방식**
- 기본은 항상 1:1
- 전문가 "초대" 행위가 있어야만 전환됨
- AI 응답 하단 버튼으로도 빠른 전환 가능

### 2-3. 페르소나 활성화 시점

**고민**: 전문가가 언제 등장해야 하는가?

**위험 시나리오**:
- 첫 사용자가 패널을 열었더니 전문가 의견이 이미 있음
- "나는 요청 안 했는데 왜 여기서 말하고 있지?"
- "대화하는 데가 2군데야?" → 혼란

**핵심 원칙 도출**: 페르소나는 사용자가 명시적으로 "초대"한 후에만 존재해야 함

**패널 기본 상태**:
- 전문가 목록은 보이되, "아직 초대된 전문가가 없습니다" 상태
- [초대] 버튼으로 사용자가 직접 활성화
- 초대된 전문가는 "대기 중" 상태로 표시

### 2-4. 대화 공간 통일성

**고민**: 패널과 채팅이 별개의 대화 공간으로 느껴지는 문제

**결론**:
- 대화 공간은 **항상 1개** (중앙 채팅 영역)
- 패널은 **전문가 관리용** (초대/해제/설정)이지 대화 공간이 아님
- 전문가 응답은 채팅 영역에 말풍선으로 표시

### 2-5. 전환 시 기존 대화 처리

**고민**: 모드 전환 시 이전 메시지는 어떻게 되는가?

**결론**:
- 기존 대화는 그대로 유지
- 새 메시지부터 전환된 형식으로 표시
- 시스템 메시지로 전환 사실을 알림 ("🎭 마케터, 분석가가 참여했습니다")

### 2-6. AI 응답 하단 액션 버튼

**고민**: 어떤 버튼이 필요한가?

**결론**:
- 1:1 모드: `📋 복사` `👍` `🌿 분기` `🎭 전문가에게 물어보기`
- 페르소나 모드 (각 말풍선): `📋 복사` `🌿 이 의견으로 분기`

## 3. 사용자 시나리오 검증

### 시나리오 1: 완전 신규 사용자
```
앱 열기 → 중앙 채팅만 보임 → 질문 → AI 답변 (GPT 스타일)
→ 패널을 열어도 "전문가 없음" 상태 → 혼란 없음
✅ 통과
```

### 시나리오 2: 1:1만 사용하는 사용자
```
질문 → AI 답변 → 다음 질문 → 전문가 안 부름
→ GPT와 동일한 경험 → 패널은 열지도 않음
✅ 통과
```

### 시나리오 3: 1:1 중 다른 시각이 궁금해진 사용자
```
질문 → AI 답변 → "🎭 전문가에게 물어보기" 클릭
→ 전문가 선택 팝업 → 선택한 전문가가 말풍선으로 답변
→ 맥락 표시줄 변경 → 이후 질문은 전문가에게도 전달
✅ 통과
```

### 시나리오 4: 처음부터 토론을 원하는 사용자
```
앱 열기 → 패널 열기 → 전문가 3명 초대
→ 시스템 메시지: "🎭 3명 참여"
→ 맥락 표시줄: "🎭 토론 중"
→ 질문 → 전문가 3명 말풍선 답변
✅ 통과
```

### 시나리오 5: 전문가 초대 후 뭘 해야 할지 모르는 사용자
```
패널 열기 → 전문가 초대
→ 채팅에 시스템 메시지: "🎭 OOO가 참여했습니다. 질문을 입력하면 전문가가 답변합니다."
→ 안내 메시지로 다음 행동 유도
✅ 통과
```

### 시나리오 6: 토론 중 1:1로 돌아가고 싶은 사용자
```
전문가 토론 중 → 맥락 표시줄에서 "🤖 1:1로 전환" 클릭
→ 시스템 메시지: "🤖 1:1 대화로 돌아갑니다"
→ 이후 질문은 AI만 답변 (GPT 스타일)
✅ 통과
```

## 4. 최종 결정 사항

### 4-1. 두 가지 대화 모드

| | 1:1 모드 (기본) | 페르소나 모드 (전환 시) |
|---|---|---|
| **사용자 메시지** | 오른쪽 정렬, 회색 라운드 버블 | 동일 |
| **AI/전문가 응답** | 왼쪽 전체 너비 블록, 버블 없음 | 좌측 정렬 말풍선, 색상별 구분 |
| **아바타** | AI 아이콘 (좌상단) | 전문가별 아이콘 + 이름 태그 |
| **액션 버튼** | 복사, 좋아요, 분기, 전문가 물어보기 | 복사, 이 의견으로 분기 |

### 4-2. 전문가(페르소나) 시각 구분 - 3요소

각 전문가는 다음 3가지로 구분:
1. **아이콘** (이모지): 🎯 마케터, 📊 분석가, 😈 비평가
2. **이름 태그**: 말풍선 위에 작은 텍스트로 표시
3. **고유 색상**: 말풍선 좌측 컬러바 또는 테두리 색상

### 4-3. 모드 전환 방식 (하이브리드)

**전환 진입점 (2가지)**:
1. **AI 응답 하단 버튼**: "🎭 전문가에게 물어보기" → 전문가 선택 팝업 → 전환
2. **우측 패널**: 전문가 초대 → 자동 전환

**전환 해제 (2가지)**:
1. **맥락 표시줄**: "🤖 1:1로 전환" 버튼 클릭
2. **우측 패널**: 모든 전문가 해제

### 4-4. 맥락 표시줄 (입력창 위)

항상 현재 대화 상태를 표시:
```
[1:1 모드]       🤖 AI와 대화 중
[페르소나 모드]   🎭 마케터, 분석가와 토론 중  [🤖 1:1 전환]
[전문가 대기]     🎭 전문가 2명 대기 중        [🤖 1:1 전환]
```

### 4-5. 패널 역할 재정의

- **이전**: 전문가 의견을 읽기 전용으로 표시하는 공간
- **이후**: 전문가를 관리(초대/해제/설정)하는 공간
- 대화는 **항상 중앙 채팅 영역에서만** 이루어짐

패널 기본 상태:
```
🎭 조언자
─────────────
아직 초대된 전문가가 없습니다

[+ 전문가 초대하기]

추천 전문가:
🎯 마케터       [초대]
📊 분석가       [초대]
😈 비평가       [초대]
```

### 4-6. 시스템 메시지 (상태 전환 알림)

모드가 바뀔 때 채팅 영역에 표시:
- `"🎭 마케터, 분석가가 참여했습니다. 질문을 입력하면 각 전문가가 답변합니다."`
- `"🤖 1:1 대화로 돌아갑니다."`
- `"🎯 마케터가 퇴장했습니다."`

### 4-7. 핵심 원칙 (4가지)

1. **페르소나는 초대 후에만 존재** - 사용자가 부르지 않으면 등장하지 않음
2. **대화 공간은 항상 1개** - 채팅 영역만 대화 공간, 패널은 관리용
3. **상태 전환 시 시스템 메시지** - 사용자가 맥락을 놓치지 않도록
4. **맥락 표시줄로 현재 상태 항시 표시** - 지금 누구와 대화 중인지 명확히

## 5. 코드 변경 범위

### chat.js
- `chatMode` 상태 추가 ('standard' | 'persona')
- `renderStandardMessage()` - 1:1 GPT 스타일
- `renderPersonaMessage()` - 다중 페르소나 말풍선
- `renderSystemMessage()` - 시스템 알림
- `toggleChatMode()` - 모드 전환
- `inviteExpert()` / `removeExpert()` - 전문가 관리

### style.css
- `.standard-mode .user-message` - 오른쪽 정렬 버블
- `.standard-mode .ai-message` - 전체 너비 블록
- `.persona-mode .persona-bubble` - 색상별 말풍선
- `.persona-name-tag` - 이름 태그
- `.context-bar` - 맥락 표시줄
- `.system-message` - 시스템 알림 스타일
- `.message-actions` - 응답 하단 액션 버튼

### index.html
- 맥락 표시줄 HTML 추가 (입력창 위)
- 패널 내부 구조 변경 (전문가 초대 UI)

### panel.js
- 전문가 초대/해제 이벤트
- 채팅 모드와 연동

### data.js
- perspectives 데이터에 color 속성 추가
- activeExperts 상태 추가
