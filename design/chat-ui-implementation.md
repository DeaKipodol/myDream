## 2. 구현된 기능 (모듈별)

### 모듈 1: 1:1 모드 GPT 스타일 레이아웃

| 항목 | 내용 |
|------|------|
| 사용자 메시지 | 오른쪽 정렬 버블 스타일 |
| AI 메시지 | 좌측 아이콘(🤖) + 콘텐츠 가로 배치 |
| 액션 버튼 | 복사, 좋아요, 분기, 전문가에게 물어보기 (호버 시 표시) |

### 모듈 2: 컨텍스트 바 + 시스템 메시지

| 항목 | 내용 |
|------|------|
| 컨텍스트 바 | 현재 모드 표시 ("AI와 대화 중" / "OOO와 토론 중") |
| 모드 전환 | 1:1 전환 버튼으로 표준 모드 복귀 |
| 시스템 메시지 | 전문가 참여/퇴장 알림 (중앙 정렬) |

### 모듈 3: 패널 리디자인 (전문가 관리)

| 항목 | 내용 |
|------|------|
| 빈 상태 UI | "아직 초대된 전문가가 없습니다" |
| 참여 중 섹션 | 초대된 전문가 + [해제] 버튼 |
| 추천 전문가 | 미초대 전문가 + [초대] 버튼 |
| 전문가 색상 | 각 전문가별 고유 색상 적용 |

### 모듈 4: 페르소나 모드 말풍선

| 항목 | 내용 |
|------|------|
| 전문가 아바타 | 색상 배경 + 이모지 |
| 이름 태그 | 전문가별 색상으로 표시 |
| 말풍선 | 좌측 색상 바 + 콘텐츠 |
| 액션 버튼 | 복사, 이 의견으로 분기 |

### 모듈 5: 모드 전환 통합

| 항목 | 내용 |
|------|------|
| 전문가 선택 팝업 | "🎭 전문가에게 물어보기" 클릭 시 모달 |
| 양방향 연동 | 패널 ↔ 채팅 상태 동기화 |
| 중복 방지 | 같은 전문가 중복 초대 차단 |

## 3. 레이아웃 개선 (GPT 스타일 적용)

### 3.1 스크롤바 위치 수정

**문제:**
```
Before: 스크롤바가 대화 콘텐츠 바로 옆에 위치
        → 좁고 답답한 느낌, "위젯" 같은 인상
```

**해결:**
```
After:  스크롤바가 chat-area 전체 우측에 위치
        → 넓고 여유로운 느낌, "전체 화면 앱" 인상
```

**코드 변경:**
```css
/* Before */
.chat-messages { overflow-y: auto; }

/* After */
.chat-area { overflow-y: auto; }
.chat-messages { /* overflow 제거 */ }
```

### 3.2 고정 요소 (Sticky Positioning)

| 요소 | 위치 | 설정 |
|------|------|------|
| `.chat-header` | 상단 고정 | `position: sticky; top: 0` |
| `.context-bar` | 하단 고정 | `position: sticky; bottom: 80px` |
| `.chat-input-area` | 하단 고정 | `position: sticky; bottom: 0` |

### 3.3 반응형 너비

| 화면 크기 | max-width |
|-----------|-----------|
| 기본 | 900px |
| 1400px+ | 1000px |
| 1600px+ | 1100px |
| 1920px+ | 1200px |

## 4. UI/UX 전문가 토론 요약

**참여자:** 민지(시각), 준호(프론트엔드), 수진(UX리서처), 동현(접근성)

### 핵심 인사이트

> "스크롤바 위치 하나가 전체 앱의 '프리미엄 느낌'을 결정한다"
> — 수진 (UX 리서처)

> "5분짜리 수정이 사용자 경험을 완전히 바꾼다"
> — 준호 (프론트엔드)

### GPT vs 우리 UI 비교

**GPT UI:**
```
┌─────────────────────────────────────────────────────┐
│  [사이드바]  │      [대화 콘텐츠]          │ 스크롤 │
│              │  ┌───────────────────────┐  │   ▲   │
│              │  │ 메시지들...           │  │   █   │ ← 브라우저 우측
│              │  └───────────────────────┘  │   ▼   │
└─────────────────────────────────────────────────────┘
```

**우리 UI (수정 전):**
```
┌─────────────────────────────────────────────────────┐
│ [사이드바] │   ┌─────────────────┐ 스크롤│         │
│            │   │ 메시지들...     │  ▲   │         │ ← 콘텐츠 안쪽
│            │   └─────────────────┘  ▼   │         │
└─────────────────────────────────────────────────────┘
```
