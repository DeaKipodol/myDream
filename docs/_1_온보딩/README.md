# AI 에이전트 온보딩

**이 폴더의 목적**: AI 에이전트가 프로젝트에 참여할 때 가장 먼저 읽는 진입점.
**관리 책임**: PM

---

## 필수 읽기 순서

| 순서 | 문서 | 목적 |
|------|------|------|
| 1 | `../../CLAUDE.md` | 개발 환경, 아키텍처, 명령어, 테스트 패턴 |
| 2 | `프로젝트_개요.md` | 프로젝트 정체성, 핵심 컨셉, 역할 체계 |
| 3 | `문서_네비게이터.md` | 전체 문서 지도 (파일 경로 + 용도) |

---

## 역할별 추가 필수 읽기

온보딩 3개 문서를 읽은 후, 배정받은 역할의 `_현재_작업.md`를 읽고 작업을 시작한다.

| 역할 | 진입점 |
|------|--------|
| PM | `docs/_3_현재작업폴더/PM_관리/_현재_작업.md` |
| 아키텍처설계자 | `docs/_3_현재작업폴더/아키텍처설계/_현재_작업.md` |
| 백엔드 개발자 | `docs/_3_현재작업폴더/초기개발/BackEnd/_현재_작업.md` |
| 프론트엔드 개발자 | `docs/_3_현재작업폴더/초기개발/FrontEnd /_현재_작업.md` |

> 참고: `_3_현재작업폴더/`는 `.gitignore`에 포함되어 프라이빗 작업 공간에만 존재한다.

---

## 작업 시작/종료 규칙 (요약)

1. **시작**: 내 역할의 `_현재_작업.md` 읽기 -> 참조 문서 읽기 -> 상태를 "진행 중"으로 갱신
2. **작업 중**: 의사결정/소통은 반드시 문서화
3. **세션 종료**: `_현재_작업.md`에 어디까지 했고 다음에 뭘 할지 기록
4. **Phase 완료**: `_4_이전작업폴더/`로 아카이브 + 협업 요약 작성

> 상세 규칙: `docs/_3_현재작업폴더/작업_문서_규칙.md`
