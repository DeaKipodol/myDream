## 🤖 AI 에이전트 Quick Start

### Git 작업 전 필수 체크리스트

1. **파일 위치 확인**
   - 이 파일이 공개 가능한가? → [레포지토리_분류.md](./레포지토리_분류.md) 참조
   - 공개 레포 vs 프라이빗 레포 중 어디에 커밋할 것인가?

2. **브랜치 확인**
   - main 브랜치에 직접 커밋하지 않기
   - develop 또는 feature 브랜치 사용

3. **커밋 메시지 작성**
   - Conventional Commits 규칙 준수
   - [관리_전략.md](./관리_전략.md)의 "2. 커밋 메시지 전략" 참조

4. **민감 정보 체크**
   - .env, API 키, 사업 계획 등 프라이빗 정보 확인
   - .gitignore에 포함되어 있는지 확인
