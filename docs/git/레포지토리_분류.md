## 🤖 AI 에이전트를 위한 가이드

### 레포지토리 구조 이해하기

**이 프로젝트는 2개의 Git 레포지토리로 운영됩니다:**

1. **공개 레포 (myDream)**
   - 오픈소스 코드 및 기술 문서
   - 누구나 볼 수 있음
   - 커밋 전 민감 정보 체크 필수

2. **프라이빗 레포 (myDream-private)**
   - 사업 계획, 내부 작업 문서
   - 공개 레포를 서브모듈로 포함
   - 모든 내부 작업은 여기서 진행

### AI가 작업 시 주의사항

#### ✅ 코드 작업 시
```bash
# 공개 레포에서 작업
cd myDream/
git checkout develop
git checkout -b feature/새기능

# 작업 후 커밋
git add core/ cli/ tests/
git commit -m "feat(core): 새 기능 추가"
```

#### ✅ 문서 작업 시 - 공개 문서
```bash
# 공개 레포에서 작업
cd myDream/
git checkout develop
git checkout -b docs/문서명

# 작업 후 커밋
git add docs/_2_기능명세/
git commit -m "docs: 기능 명세서 업데이트"
```

#### ✅ 문서 작업 시 - 내부 문서
```bash
# 프라이빗 레포에서 작업
cd myDream-private/
git checkout main

# 작업 후 커밋
git add What_I_wanted/ docs_private/
git commit -m "docs: 사업 계획 업데이트"
```

#### ❌ 절대 하지 말아야 할 것
```bash
# 잘못된 예시 - 민감 정보를 공개 레포에 커밋
cd myDream/
git add What_I_wanted/  # ❌ 이 폴더는 프라이빗 전용!
git commit -m "docs: 비전 문서 추가"  # ❌ 절대 안됨!
```

### AI가 파일 위치 판단하기

**파일을 생성/수정하기 전 체크리스트:**

1. ❓ 이 파일이 **오픈소스로 공개해도 되는가**?
   - YES → 공개 레포 (`myDream/`)
   - NO → 프라이빗 레포 (`myDream-private/`)

2. ❓ 이 파일이 **사업 계획, 전략, 특허** 관련인가?
   - YES → 프라이빗 레포
   - NO → 다음 단계로

3. ❓ 이 파일이 **코드, 테스트, 기술 문서**인가?
   - YES → 공개 레포
   - NO → 프라이빗 레포 (기본값)

### 경로 매핑표

| 파일 종류 | 공개 레포 경로 | 프라이빗 레포 경로 |
|----------|----------------|-------------------|
| 소스 코드 | `myDream/core/` | - |
| CLI 코드 | `myDream/cli/` | - |
| 테스트 | `myDream/tests/` | - |
| 기능 명세 | `myDream/docs/_2_기능명세/` | - |
| 공개 문서 | `myDream/docs/` | - |
| **설계 문서** | - | `myDream-private/design/` |
| 사업 계획 | - | `myDream-private/What_I_wanted/` |
| AI 작업 기록 | - | `myDream-private/ai-thinking-workspace/` |
| 특허 문서 | - | `myDream-private/docs_private/특허/` |
| 현재 작업 | - | `myDream-private/docs_private/_3_현재작업폴더/` |
| 이전 작업 | - | `myDream-private/docs_private/_4_이전작업폴더/` |

## ⚠️ 주의사항

1. **절대 공개 레포에 민감 정보 커밋 금지**
   - .gitignore에 프라이빗 폴더 명시됨
   - 하지만 실수 방지를 위해 항상 확인

2. **서브모듈 업데이트 잊지 않기**
   - 공개 레포 작업 후 프라이빗 레포에서 서브모듈 업데이트

3. **두 레포지토리의 역할 명확히 구분**
   - 공개: 코드 + 기술 문서
   - 프라이빗: 사업 계획 + 내부 작업

4. **AI 에이전트는 항상 이 문서를 참조**
   - 파일 생성 전 위치 확인
   - 커밋 전 레포지토리 확인
