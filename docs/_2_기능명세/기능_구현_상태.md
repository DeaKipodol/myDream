## Phase CLI-3: 분기 병합 (LCA 알고리즘) ⏳ 대기

**상세 명세**: [분기_병합_LCA_명세.md](./분기_병합_LCA_명세.md)

### LCA 알고리즘
- ⏳ 최소 공통 조상 찾기 (find_lca)
- ⏳ 두 노드 간 경로 찾기 (get_path_between)
- ⏳ 분기점 및 각 경로 반환 (get_divergence_point)

### 병합 전략
- ⏳ 순차 병합 (sequential) - 모든 내용 포함
- ⏳ 요약 병합 (summary) - 토큰 절약
- ⏳ 커스텀 병합 (custom) - 사용자 선택

### 병합 로직
- ⏳ MergeManager 클래스
- ⏳ merge_nodes() - 두 노드 병합
- ⏳ preview_merge() - 병합 미리보기
- ⏳ suggest_merges() - 병합 추천

### CLI 명령어
- ⏳ `merge <n1> <n2> --question "질문"` - 기본 병합
- ⏳ `merge <n1> <n2> --dry-run` - 미리보기만
- ⏳ `merge <n1> <n2> --summary` - 요약 모드
- ⏳ `merge <n1> <n2> --select n3,n5` - 커스텀 노드 선택
- ⏳ `lca <n1> <n2>` - LCA 확인
- ⏳ `merge --suggest` - 병합 추천

### 데이터 구조
- ⏳ MergeNode 메타데이터 정의
- ⏳ 병합 이력 추적 (merge_history)

### 충돌 해결
