## 기능 개요

### 핵심 컨셉

**같은 질문에 대해 여러 AI 에이전트(페르소나)가 각자의 관점에서 답변**하는 기능입니다. 마치 회의실에 여러 전문가가 있어 각자의 시각으로 조언하는 것과 같습니다.

### 예시

```
질문: "신규 기능을 개발해야 할까?"

🎯 마케터 (Marketer):
"고객 피드백을 보면 이 기능에 대한 수요가 높습니다.
경쟁사도 유사 기능을 출시했으니 시장 경쟁력을 위해 개발을 추천합니다."

💰 CFO (Financial Officer):
"개발 비용 500만원 대비 예상 매출 증가는 월 100만원입니다.
ROI는 5개월이므로 재무적으로 타당합니다."

😈 악마의 대변인 (Devil's Advocate):
"하지만 개발 일정이 지연될 위험이 있고, 핵심 기능 개선을 미루게 됩니다.
정말 지금이 맞는 타이밍일까요?"

🔬 엔지니어 (Engineer):
"기술적으로 구현 가능하지만, 기존 아키텍처와 충돌할 수 있습니다.
리팩토링이 선행되어야 할 수 있습니다."
```

## 왜 획기적인가

### 일반 챗봇의 한계

1. **단일 관점**: 하나의 AI가 하나의 답변
2. **프롬프트 엔지니어링 필요**: 다른 관점을 얻으려면 질문을 다르게 해야 함
3. **맥락 재설정**: 여러 관점을 얻으려면 대화를 여러 번 반복

### 우리 시스템의 차별점

1. **동시 다발적 관점**: 한 번의 질문으로 여러 관점 획득
2. **일관된 컨텍스트**: 모든 에이전트가 같은 대화 맥락 공유
3. **구조화된 의사결정**: 체계적으로 다각도 검토 가능

### 실제 가치

#### 1. 의사결정 품질 향상

```
단일 AI:
"기능을 개발하는 것이 좋습니다."
→ 한 쪽 면만 보고 결정

다중 에이전트:
"마케터: 필요, CFO: 타당, 악마: 위험, 엔지니어: 가능"
→ 모든 측면을 고려한 균형잡힌 결정
```

#### 2. 블라인드 스팟 발견

```
긍정적 관점만 보다가
→ 악마의 대변인이 숨겨진 리스크 지적
→ 사전에 대비책 마련
```

#### 3. 회의 시뮬레이션

```
실제 팀 회의 전에
→ 다중 관점으로 사전 검토
→ 예상 질문과 답변 준비
```

## 동작 방식

### 아키텍처

```python
class PerspectiveManager:
    """다중 관점 관리 클래스"""

    def __init__(self, ai_client: AIClient):
        self.ai_client = ai_client
        self.personas = self._load_default_personas()

    def ask_multiple_perspectives(
        self,
        question: str,
        conversation_history: List[Dict[str, str]],
        selected_personas: List[str] = None
    ) -> Dict[str, str]:
        """
        여러 페르소나에게 같은 질문

        Args:
            question: 질문 내용
            conversation_history: 대화 맥락
            selected_personas: 사용할 페르소나 목록 (None이면 전체)

        Returns:
            {persona_name: response, ...}
        """
        personas_to_use = selected_personas or list(self.personas.keys())
        responses = {}

        for persona_name in personas_to_use:
            persona = self.personas[persona_name]

            # 페르소나별 시스템 프롬프트 추가
            messages = [
                {"role": "system", "content": persona.system_prompt}
            ]

            # 대화 맥락 추가
            messages.extend(conversation_history)

            # 질문 추가
            messages.append({
                "role": "user",
                "content": question
            })

            # AI 호출
            response = self.ai_client.chat_with_messages(messages)
            responses[persona_name] = response

        return responses
```

### 데이터 구조

```python
@dataclass
class Persona:
    """페르소나 정의"""
    name: str
    icon: str
    role: str
    system_prompt: str
    focus_areas: List[str]
    color: str = "#000000"  # UI 색상

@dataclass
class MultiPerspectiveNode(Node):
    """다중 관점 노드"""
    user_question: str
    ai_answers: Dict[str, str]  # {persona_name: answer}
    metadata: Dict[str, Any] = field(default_factory=lambda: {
        "is_multi_perspective": True,
        "personas_used": [],
        "timestamp": ""
    })
```

### 노드 저장 전략

#### 전략 1: 단일 노드에 모든 답변 저장

```python
node = MultiPerspectiveNode(
    user_question="신규 기능을 개발해야 할까?",
    ai_answers={
        "Marketer": "고객 니즈가 높으므로 개발 추천...",
        "CFO": "ROI가 긍정적이므로 타당...",
        "Devil's Advocate": "하지만 리스크가 있음..."
    }
)
```

#### 전략 2: 각 페르소나마다 자식 노드 생성

```
[Root]
  └─ [n1: "신규 기능 개발?"] ← 원본 질문
      ├─ [n2: Marketer 답변]
      ├─ [n3: CFO 답변]
      ├─ [n4: Devil's Advocate 답변]
      └─ [n5: Engineer 답변]
```

**권장**: 전략 1 (단일 노드) - 관점들을 하나의 단위로 관리

## 사용 시나리오

### 시나리오 1: 의사결정

```bash
$ ask-multi "신규 기능 A를 개발해야 할까?"

🎯 Marketer:
고객 설문 결과 65%가 이 기능을 원합니다.
경쟁사 B도 유사 기능을 출시했으므로 시장 경쟁력을 위해 개발을 추천합니다.

💰 CFO:
- 개발 비용: 500만원
- 예상 매출 증가: 월 100만원
- 회수 기간: 5개월
→ 재무적으로 타당합니다.

😈 Devil's Advocate:
현재 진행 중인 프로젝트 2개가 지연될 수 있습니다.
기능 A가 정말 핵심 가치인지 재검토가 필요합니다.

🔬 Engineer:
구현 난이도: 중
예상 기간: 3주
기존 시스템과 충돌 없음. 기술적으로 가능합니다.

✅ 종합: 4개 관점 중 3개 긍정, 1개 주의 → 진행 가능하되 리스크 모니터링 필요
```

### 시나리오 2: 전략 수립

```bash
$ switch n5  # 마케팅 전략 논의 중
$ ask-multi "SNS vs 검색 광고, 어느 쪽이 우선?" --personas marketer,cfo,data_analyst

🎯 Marketer:
타겟 고객(20-30대)은 SNS 사용률이 높으므로 SNS 우선 추천.

💰 CFO:
SNS: CPA 5000원 / 검색: CPA 8000원
예산 효율성: SNS가 유리

📊 Data Analyst:
과거 데이터 분석 결과:
- SNS: CTR 2.5%, CVR 3%
- 검색: CTR 1.5%, CVR 5%
→ 인지도는 SNS, 전환은 검색이 우수. 단계별 접근 제안.
```

### 페르소나 관리

```bash
# 사용 가능한 페르소나 목록

출력:
  🎯 marketer - 마케팅 전문가

personas show marketer
출력:
  이름: Marketer
  역할: 마케팅 및 고객 관점 전문가
  초점 영역: 고객 니즈, 시장 기회, 경쟁 분석, 브랜딩

personas add investor --icon 💼 --role "투자자" --prompt "투자자 프롬프트..."

# 페르소나 제거
personas remove investor
```

```python
# core/conversation.py 확장

class ConversationManager:
    def turn_multi_perspective(
        self,
        question: str,
        persona_names: List[str] = None
    ) -> MultiPerspectiveNode:
        """
        다중 관점 질문

        Returns:
            여러 AI 답변을 포함한 노드
        """
        history = self._build_conversation_history()
        responses = {}

        personas_to_use = persona_names or self.persona_manager.get_all_names()

        for persona_name in personas_to_use:
            persona = self.persona_manager.get_persona(persona_name)

            # 페르소나별 시스템 프롬프트
            messages = [
                {"role": "system", "content": persona.system_prompt}
            ]
            messages.extend(history)
            messages.append({"role": "user", "content": question})

            response = self.ai_client.chat_with_messages(messages)
            responses[persona_name] = response

        # 다중 관점 노드 생성
        node = self.store.add_multi_perspective_node(
            user_question=question,
            ai_answers=responses,
            personas_used=personas_to_use
        )

        return node
```

### 병렬 처리

```python
import asyncio

async def ask_multiple_perspectives_async(
    question: str,
    personas: List[Persona],
    conversation_history: List[Dict]
) -> Dict[str, str]:
    """
    비동기로 여러 페르소나에게 동시 질문
    (순차 처리 대비 3-4배 빠름)
    """
    tasks = []

    for persona in personas:
        messages = [
            {"role": "system", "content": persona.system_prompt}
        ]
        messages.extend(conversation_history)
        messages.append({"role": "user", "content": question})

        # 비동기 API 호출
        task = ai_client.chat_async(messages)
        tasks.append((persona.name, task))

    # 모든 응답 대기
    responses = {}
    for persona_name, task in tasks:
        response = await task
        responses[persona_name] = response

    return responses
```
