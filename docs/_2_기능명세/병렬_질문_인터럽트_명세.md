## 기능 개요

### 핵심 컨셉

AI가 **긴 응답을 생성하는 중**에도, 사용자는 **별도의 질문을 던질 수 있고**, 이는 **새로운 분기(자식 노드)**로 생성되어 **부모의 맥락을 공유**하면서 독립적으로 진행.

### 한 문장 요약

> "AI 응답 중 '잠깐, 이건 뭐야?'라고 물으면, 기존 응답은 계속 진행되고 새 대화 분기가 동시에 시작되는 것"

### 기존 챗봇과의 차이

```
[기존 챗봇]
AI 응답 중... (길게 생성 중)
사용자: 질문하고 싶은데?
      → ❌ 응답 끝날 때까지 기다려야 함
      → ❌ 또는 정지 버튼 누르면 응답 날림

[우리 시스템]
AI 응답 중... (길게 생성 중)
사용자: "잠깐, 이 부분 설명해줘" (인터럽트)
      → ✅ 기존 응답은 계속 진행
      → ✅ 새 질문은 별도 분기로 즉시 처리
      → ✅ 두 대화 모두 보존됨
```

## 왜 필요한가

### 문제 상황

#### 1. 긴 응답 중 궁금증 발생

```
사용자: "React 훅스 전체를 설명해줘"

AI: "React 훅스는 함수형 컴포넌트에서 상태와 생명주기를...

     1. useState
     useState는 상태를 관리하는 훅입니다...
     [50줄 설명 중...]

     2. useEffect  ← 여기서 궁금증 발생!
     useEffect는 사이드 이펙트를 처리..."

사용자: (생각) "useState 예제를 좀 더 보고 싶은데...
        근데 아직 응답 중이라 질문 못하네..."

❌ 문제:
- 응답 끝날 때까지 기다려야 함 (지루함)
- 정지 버튼 누르면 나머지 내용 못 봄 (손실)
- 질문하고 싶은 순간을 놓침 (맥락 잃음)
```

#### 2. 탐색적 대화의 제약

```
사용자: "마이크로서비스 아키텍처 설계해줘"

AI: [긴 설계 문서 생성 중... 2분 소요]

사용자: (중간에 생각)
        "아, 데이터베이스 전략부터 먼저 정하고 싶은데
         근데 AI가 계속 생성 중이라..."

❌ 문제: 생각의 흐름을 방해함
```

#### 3. 멀티태스킹 불가

```
사용자: "이 코드 리팩토링해줘" (큰 파일)

AI: [200줄 코드 생성 중... 3분 소요]

사용자: "아, 그동안 테스트 코드도 물어볼까?"
        → ❌ 기다려야 함

사용자: "아니면 다른 질문이라도..."
        → ❌ 여전히 기다려야 함
```

### 우리의 해결책

```
✅ 인터럽트 허용
- AI 응답 중에도 언제든 새 질문 가능

✅ 병렬 처리
- 기존 응답은 백그라운드에서 계속
- 새 질문은 즉시 처리

✅ 맥락 공유
- 새 질문은 부모 노드까지의 맥락 공유
- 완전히 새로운 대화가 아님

✅ 모두 보존
- 기존 응답도 완료되어 저장
- 새 질문 응답도 저장
- 트리 구조로 나중에 확인 가능
```

## 동작 방식

### 기본 흐름

```
1. AI 응답 시작
   사용자: "React 훅스 전체 설명해줘"
   AI: [스트리밍 응답 시작...]

2. 사용자 인터럽트 (중간에 질문)
   사용자: [Ctrl+I] "useState 예제 더 보여줘"

3. 시스템 동작
   a. 기존 응답 일시정지
   b. 현재까지 생성된 내용을 임시 노드로 저장
   c. 새 질문을 형제 노드로 생성
   d. 새 질문 처리 시작

4. 병렬 진행
   - 새 질문 응답 진행
   - 기존 응답은 백그라운드에서 계속

5. 완료
   - 두 응답 모두 완료 및 저장
   - 트리 구조:
     [부모]
       ├─ [원래 질문 응답] (완료)
       └─ [인터럽트 질문 응답] (완료)
```

### 트리 구조 예시

```
Before (인터럽트 전):
[Root]
  └─ [n1: "React 훅스 설명해줘"]
      └─ [n2: 응답 생성 중... 30%]

User Interrupt:
"useState 예제 더 보여줘"

After (인터럽트 후):
[Root]
  └─ [n1: "React 훅스 설명해줘"]
      ├─ [n2: 원래 응답 계속 생성... 50%]
      └─ [n3: "useState 예제 더 보여줘" - 새 응답 시작]

Final (모두 완료):
[Root]
  └─ [n1: "React 훅스 설명해줘"]
      ├─ [n2: 원래 응답 ✓ 완료]
      └─ [n3: useState 예제 ✓ 완료]
```

## 구현 계획

### Phase 1: 스트리밍 중단 처리 (2일)

```python
# core/conversation.py

class ConversationManager:
    def __init__(self):
        self.active_streams = {}  # 진행 중인 응답

    async def turn_with_stream(
        self,
        question: str,
        on_chunk: Callable = None
    ) -> Node:
        """스트리밍 응답 생성"""
        stream_id = generate_id()

        # 스트림 등록
        self.active_streams[stream_id] = {
            'question': question,
            'chunks': [],
            'status': 'running',
            'pause_event': asyncio.Event()
        }

        try:
            async for chunk in self.ai_client.stream(question):
                # 일시정지 확인
                if self.active_streams[stream_id]['status'] == 'paused':
                    await self.active_streams[stream_id]['pause_event'].wait()

                # 청크 저장
                self.active_streams[stream_id]['chunks'].append(chunk)

                # 콜백 호출
                if on_chunk:
                    on_chunk(chunk)

            # 완료
            full_response = ''.join(
                self.active_streams[stream_id]['chunks']
            )

        finally:
            del self.active_streams[stream_id]

        return self.store.add_child_to_current(question, full_response)

    def pause_stream(self, stream_id: str):
        """스트림 일시정지"""
        if stream_id in self.active_streams:
            self.active_streams[stream_id]['status'] = 'paused'

    def resume_stream(self, stream_id: str):
        """스트림 재개"""
        if stream_id in self.active_streams:
            self.active_streams[stream_id]['status'] = 'running'
            self.active_streams[stream_id]['pause_event'].set()
```

### Phase 2: 인터럽트 처리 (2-3일)

```python
class ConversationManager:
    async def interrupt_and_ask(
        self,
        new_question: str,
        background_stream_id: str = None
    ) -> Node:
        """
        진행 중인 응답을 백그라운드로 보내고
        새 질문 처리

        Args:
            new_question: 새 질문
            background_stream_id: 백그라운드로 보낼 스트림 ID

        Returns:
            새 질문의 노드
        """
        # 1. 기존 스트림 백그라운드로
        if background_stream_id:
            self.move_to_background(background_stream_id)

        # 2. 현재까지의 임시 노드 생성 (선택)
        if background_stream_id:
            partial_response = ''.join(
                self.active_streams[background_stream_id]['chunks']
            )
            # 임시 노드는 나중에 완전한 응답으로 업데이트

        # 3. 새 질문 처리 (새 분기)
        new_node = await self.turn_with_stream(new_question)

        return new_node

    def move_to_background(self, stream_id: str):
        """스트림을 백그라운드로 이동"""
        if stream_id in self.active_streams:
            self.active_streams[stream_id]['background'] = True
            self.active_streams[stream_id]['priority'] = 'low'
```

### Phase 3: 백그라운드 작업 관리 (2일)

```python
class BackgroundTaskManager:
    """백그라운드 응답 관리"""

    def __init__(self):
        self.tasks = {}

    def create_task(
        self,
        task_id: str,
        coroutine: Coroutine
    ):
        """백그라운드 작업 생성"""
        task = asyncio.create_task(coroutine)
        self.tasks[task_id] = {
            'task': task,
            'status': 'running',
            'created_at': datetime.now()
        }

    def get_active_tasks(self) -> List[Dict]:
        """진행 중인 작업 목록"""
        return [
            {
                'id': task_id,
                'status': info['status'],
                'created_at': info['created_at']
            }
            for task_id, info in self.tasks.items()
            if not info['task'].done()
        ]

    async def cancel_task(self, task_id: str):
        """작업 취소"""
        if task_id in self.tasks:
            self.tasks[task_id]['task'].cancel()
            await asyncio.sleep(0)  # 취소 처리 대기
```

```javascript
// frontend/streaming.js

class StreamingManager {
  constructor() {
    this.activeStreams = new Map();
  }

  async startStream(question) {
    const streamId = generateId();

    // 스트림 UI 생성
    const streamUI = this.createStreamUI(streamId, question);

    // SSE 연결
    const eventSource = new EventSource(
      `/api/stream/${streamId}`
    );

    eventSource.onmessage = (event) => {
      const chunk = JSON.parse(event.data);

      // UI 업데이트
      streamUI.appendChunk(chunk.content);
      streamUI.updateProgress(chunk.progress);
    };

    this.activeStreams.set(streamId, {
      eventSource,
      ui: streamUI
    });

    return streamId;
  }

  interrupt(streamId, newQuestion) {
    // 기존 스트림을 백그라운드로
    const stream = this.activeStreams.get(streamId);
    if (stream) {
      stream.ui.moveToBackground();
    }

    // 새 질문 시작
    this.startStream(newQuestion);

    // 서버에 인터럽트 알림
    fetch(`/api/interrupt/${streamId}`, {
      method: 'POST',
      body: JSON.stringify({ newQuestion })
    });
  }

  showTaskManager() {
    // 작업 관리 사이드바 표시
    const tasks = Array.from(this.activeStreams.entries());

    return `
      <div class="task-manager">
        <h3>진행 중인 응답</h3>
        ${tasks.map(([id, stream]) => `
          <div class="task-item">
            <span>${stream.question}</span>
            <button onclick="viewStream('${id}')">보기</button>
            <button onclick="cancelStream('${id}')">취소</button>
          </div>
        `).join('')}
      </div>
    `;
  }
}
```
