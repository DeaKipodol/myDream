## 기능 개요

### 핵심 컨셉

AI와 대화하면서 **언제든 접근 가능한 개인 메모 공간**. 작업 내용을 정리하고, 다음 할 일을 기록하며, 자주 쓰는 명령과 페르소나를 관리하는 **빠른 메모장**.

### 한 문장 요약

> "AI와의 대화 중 생각을 정리하고, 다음 작업을 계획하며, AI가 이를 읽고 참조할 수 있는 개인 작업 노트"

### 작업 공간(Workspace)과의 차이

| 구분 | 메모장 (Scratchpad) | 작업 공간 (Workspace) |
|------|---------------------|----------------------|
| 목적 | 빠른 메모, 임시 기록 | 실제 파일 편집 |
| 지속성 | 휘발성 (세션 내) | 영구 저장 |
| 버전 관리 | 간단한 이력 | Git 수준 diff/rollback |
| AI 개입 | 읽기만 | 편집 제안 |
| 사용 패턴 | 수시로 짧게 | 집중해서 길게 |

## 왜 필요한가

### 현재 AI 도구의 문제점

#### 1. 컨텍스트 공유의 번거로움

```
사용자의 현재 작업 흐름:
1. 메모장(외부)에 작업 내용 정리
2. AI에게 지시할 때 → 복사
3. AI 채팅창에 → 붙여넣기
4. 반복...

문제: 복사-붙여넣기 피로, 컨텍스트 유실
```

#### 2. 명령 재사용의 어려움

```
자주 쓰는 지시문:
"위 내용을 마크다운으로 정리해서 docs/ 폴더에 저장해줘"
"테스트 작성하고 커버리지 확인해줘"
"타입스크립트로 변환해줘"

문제: 매번 다시 타이핑하거나 채팅 히스토리에서 찾아야 함
```

#### 3. 페르소나 설정의 번거로움

```
자주 쓰는 페르소나:
"너는 시니어 백엔드 엔지니어야. 성능과 확장성을 중시해."
"너는 기술 문서 작성 전문가야. 초보자도 이해할 수 있게 써줘."

문제: 매번 긴 페르소나 설명을 다시 입력
```

### 우리의 해결책

1. **통합 메모장**: 시스템 내부에 메모 공간 제공
2. **AI 읽기 가능**: "메모 내용 보고 진행해줘" 한 마디로 해결
3. **템플릿 관리**: 자주 쓰는 명령/페르소나를 저장하고 클릭 한 번으로 사용
4. **즉시 접근**: 대화 중 언제든 사이드바에서 메모 가능

### 상호작용

#### 메모 작성

```javascript
class ScratchpadManager {
  constructor() {
    this.textarea = document.getElementById('scratchpad-textarea');
    this.autoSave();
  }

  autoSave() {
    // 5초마다 자동 저장
    setInterval(() => {
      const content = this.textarea.value;
      localStorage.setItem('scratchpad_content', content);
      this.showSaveStatus('저장됨');
    }, 5000);
  }

  async sendToAI() {
    const content = this.textarea.value;

    // AI 컨텍스트에 메모 추가
    const message = {
      role: 'system',
      content: `[사용자의 메모장 내용]\n${content}`
    };

    // 채팅 매니저에 전달
    chatManager.addContextMessage(message);
    this.showNotification('AI가 메모를 읽었습니다');
  }
}
```

#### 명령 템플릿 사용

```javascript
class TemplateManager {
  useTemplate(templateId) {
    const template = this.templates.find(t => t.id === templateId);

    // 채팅 입력창에 자동 입력
    const chatInput = document.getElementById('chat-input');
    chatInput.value = template.command;
    chatInput.focus();

    // 옵션: 자동 전송
    if (template.autoSend) {
      chatManager.sendMessage(template.command);
    }
  }

  createTemplate(name, command, icon = '📝') {
    const template = {
      id: generateId(),
      name,
      command,
      icon,
      createdAt: new Date(),
      usageCount: 0
    };

    this.templates.push(template);
    this.save();
  }
}
```

### 3. 스마트 템플릿 생성

```javascript
// 반복되는 명령을 AI가 자동으로 템플릿 제안

class SmartTemplateGenerator {
  analyzeUsagePatterns() {
    // 최근 명령 패턴 분석
    const recentCommands = this.getRecentCommands(50);
    const patterns = this.findPatterns(recentCommands);

    // 자주 쓰는 명령이 템플릿에 없으면 제안
    patterns.forEach(pattern => {
      if (!this.isTemplateExists(pattern)) {
        this.suggestTemplate(pattern);
      }
    });
  }

  suggestTemplate(pattern) {
    // UI에 알림
    this.showNotification(
      `"${pattern.command}" 명령을 자주 사용하시네요. 템플릿으로 저장할까요?`,
      {
        onConfirm: () => {
          templateManager.createTemplate(
            pattern.suggestedName,
            pattern.command
          );
        }
      }
    );
  }
}
```

## 데이터 구조

### 메모 데이터

```typescript
interface ScratchpadData {
  content: string;           // 메모 내용 (마크다운)
  lastModified: Date;        // 마지막 수정 시간
  tags: string[];           // 태그 목록
  version: number;          // 버전 (히스토리)
}
```

### 명령 템플릿

```typescript
interface CommandTemplate {
  id: string;
  name: string;             // 템플릿 이름
  command: string;          // 명령 내용
  icon: string;             // 아이콘 (emoji)
  category: string;         // 카테고리
  usageCount: number;       // 사용 횟수
  lastUsed: Date;           // 마지막 사용
  autoSend: boolean;        // 자동 전송 여부
  createdAt: Date;
}
```

### 페르소나 프리셋

```typescript
interface PersonaPreset {
  id: string;
  name: string;             // 페르소나 이름
  icon: string;             // 아이콘
  systemPrompt: string;     // 시스템 프롬프트
  description: string;      // 설명
  focusAreas: string[];     // 초점 영역
  color: string;            // UI 색상
  isDefault: boolean;       // 기본 페르소나 여부
  createdAt: Date;
}
```
