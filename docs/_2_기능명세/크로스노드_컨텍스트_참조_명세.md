## 기능 개요

### 핵심 컨셉

일반 챗봇처럼 현재 대화 경로만 AI에게 전달하는 것이 아니라, **다른 대화 경로의 내용을 참조(reference)**하여 현재 질문의 컨텍스트로 활용할 수 있는 기능입니다.

### 일반 챗봇과의 차이

```
일반 챗봇:
[Root] → [A] → [B] → [C]  ← 현재 경로만 AI에게 전달

우리 시스템:
[Root] → [A] → [B] → [C]  ← 현재 경로
         └→ [D] → [E]      ← 이 경로도 참조 가능!
```

**예시**:
- 경로 1에서 "마케팅 전략"에 대해 논의했음
- 경로 2에서 "기술 스택"에 대해 논의 중
- 경로 2의 현재 질문에서 **경로 1의 마케팅 논의 내용을 참조**하여 "기술 스택이 마케팅 전략에 어떻게 도움이 되는지" 물어볼 수 있음

---

## 왜 획기적인가

### 일반 챗봇의 한계

1. **단일 컨텍스트 제약**: 한 번에 하나의 대화 흐름만 유지
2. **컨텍스트 전환 비용**: 다른 주제 참조하려면 복사-붙여넣기 필요
3. **정보 단절**: 여러 대화를 연결하여 종합적 인사이트 얻기 어려움

### 우리 시스템의 차별점

1. **다중 컨텍스트 통합**: 여러 대화 경로를 동시에 참조
2. **유기적 지식 연결**: 트리 구조를 활용한 자연스러운 정보 연결
3. **컨텍스트 재사용**: 한 번 논의한 내용을 다른 맥락에서 재활용

### 실제 가치

```
시나리오: 스타트업 사업 계획 수립

경로 1: 타겟 고객 분석
  → 20-30대 직장인
  → 생산성 도구 선호
  → 가격 민감도 중간

경로 2: 기술 스택 선택
  → React vs Vue 고민
  → 현재 질문: "어떤 기술 스택이 우리 타겟 고객에게 더 나은 UX를 제공할까?"
  → **경로 1을 참조**하여 AI가 고객 특성 기반 기술 선택 조언 가능
```

```python
# 현재 구조 (Phase CLI-1)
def _build_conversation_history(self) -> List[Dict[str, str]]:
    """현재 active_path만 history로 변환"""
    messages = []
    for node_id in self.store.active_path_ids:
        node = self.store.tree.get_node(node_id)
        messages.append({"role": "user", "content": node.user_question})
        messages.append({"role": "assistant", "content": node.ai_answer})
    return messages

# 새로운 구조 (Phase CLI-2)
def _build_conversation_history_with_references(
    self,
    reference_node_ids: List[str] = None
) -> List[Dict[str, str]]:
    """현재 경로 + 참조 노드들을 history로 변환"""
    messages = []

    # 1. 참조 노드들을 먼저 추가 (컨텍스트로 활용)
    if reference_node_ids:
        messages.append({
            "role": "system",
            "content": "다음은 참조할 이전 대화 내용입니다:"
        })
        for ref_id in reference_node_ids:
            node = self.store.tree.get_node(ref_id)
            messages.append({
                "role": "user",
                "content": f"[참조] {node.user_question}"
            })
            messages.append({
                "role": "assistant",
                "content": node.ai_answer
            })

    # 2. 현재 active_path 추가
    for node_id in self.store.active_path_ids:
        node = self.store.tree.get_node(node_id)
        messages.append({"role": "user", "content": node.user_question})
        messages.append({"role": "assistant", "content": node.ai_answer})

    return messages
```

```python
def calculate_context_tokens(
    active_path: List[Node],
    reference_nodes: List[Node],
    max_tokens: int = 4000  # GPT-4 기준
) -> bool:
    """컨텍스트 토큰이 제한을 초과하는지 확인"""
    total_tokens = 0

    # 참조 노드 토큰 계산
    for node in reference_nodes:
        total_tokens += estimate_tokens(node.user_question)
        total_tokens += estimate_tokens(node.ai_answer)

    # 현재 경로 토큰 계산
    for node in active_path:
        total_tokens += estimate_tokens(node.user_question)
        total_tokens += estimate_tokens(node.ai_answer)

    return total_tokens < max_tokens
```

## 구현 계획

### Phase 1: 기본 참조 (1-2일)

**목표**: 단일/복수 노드 수동 참조 가능

```python
# core/conversation.py 확장
class ConversationManager:
    def turn(
        self,
        question: str,
        reference_node_ids: List[str] = None
    ) -> Node:
        """참조 노드를 포함한 대화 턴 실행"""
        history = self._build_conversation_history_with_references(
            reference_node_ids
        )
        ai_response = self.ai_client.chat(question, history)

        # 참조 정보를 메타데이터에 저장
        node = self.store.add_child_to_current(
            user_question=question,
            ai_answer=ai_response,
            metadata={
                "reference_node_ids": reference_node_ids or [],
                "timestamp": datetime.now().isoformat()
            }
        )
        return node
```

### Phase 2: CLI 통합 (1일)

**목표**: `--ref` 플래그 추가

```python
# cli/cli.py
def cmd_ask(self, question: str, ref: str = None):
    """
    AI에게 질문하고 응답을 트리에 추가

    Args:
        question: 질문 내용
        ref: 참조할 노드 번호 (쉼표로 구분, 예: n5,n7,n12)
    """
    reference_node_ids = []
    if ref:
        # "n5,n7,n12" → ["n5", "n7", "n12"]
        ref_numbers = ref.split(',')
        for ref_num in ref_numbers:
            node_id = self.number_to_id.get(ref_num.strip())
            if node_id:
                reference_node_ids.append(node_id)

    node = self.conversation_manager.turn(
        question=question,
        reference_node_ids=reference_node_ids
    )
```

```python
def validate_references(
    active_path: List[Node],
    reference_nodes: List[Node]
) -> Tuple[bool, str]:
    """참조가 유효한지 확인"""
    if len(reference_nodes) > 10:
        return False, "참조 노드는 최대 10개까지 가능합니다"

    if not check_token_limit(active_path, reference_nodes):
```

```python
def compress_references(nodes: List[Node]) -> str:
    """참조 노드를 요약하여 토큰 절약"""
    summaries = [ai_client.summarize(node) for node in nodes]
    return "\n".join(summaries)
```
