2. 창업(품목) 아이템의 주요 내용
==================================================

[아이템의 핵심내용, 서비스 등]

핵심 내용:
트리 구조 대화 관리 시스템 - 여러 대화 경로를 동시에 관리하고, 참조하고, 병합할 수 있는 AI 상담 도구

패러다임 전환:
  기존: AI를 "비서"로 생각 (일을 시키고 사람은 아무것도 안 함)
  우리: AI는 내 머릿속 생각을 "시각화"하고 "발전"시켜주는 "도구"
  핵심: AI는 "사고"를 돕는 "도구"

서비스 설명:

1. 주제 분류 및 시각화 (트리 구조)
   - 대화 진행 중 주제 자동 분석 및 분류
   - 분류된 주제 클릭하면 해당 대화로 즉시 이동 (스크롤 불필요)
   - 이전과 다른 질문 가능 (분기 생성)
   - 사고 전개 과정을 시각적으로 표현

2. RAG 시스템 (자료 제한 제거)
   - 기존 AI: 20~50개 파일 제한
   - 우리: 무제한 파일 업로드 가능
   - 한라대학교 RAG 시스템 구축 경험 (400개 파일, 수천 문서)

3. 다중 관점 (페르소나 모드)
   - 한 질문에 여러 AI 전문가가 각자 답변
   - 예: 마케터, 분석가, 비평가가 동시에 의견 제시
   - 전문가별 색상 구분 말풍선


[아이템 개념도, 서비스 구성도, 서비스 주요내용]

개념도:

선형 대화의 문제:
  질문1 → 답변1
    ↓
  질문2 → 답변2
    ↓
  질문3 → 답변3
    ↓
  질문1 내용 찾기? → 스크롤 30번 이상!

우리의 솔루션 (트리 구조):
  Root
    ├─ 질문1 → 답변1
    │   ├─ 질문2a → 답변2a
    │   └─ 질문2b → 답변2b
    └─ 질문3 → 답변3

  클릭 1번으로 즉시 이동!

서비스 구성도:

  Frontend (Web UI)
    - GPT 스타일 대화 인터페이스
    - 트리 시각화 (좌측 사이드바)
    - 페르소나 모드 (우측 패널)
        ↓
  Backend API (FastAPI)
    - 대화 관리 (ConversationManager)
    - 트리 관리 (Store)
    - 체크포인트 관리
        ↓
  OpenAI API (GPT-4)  +  RAG System (Vector DB)

주요 내용 (문제 → 솔루션):

선형 대화 구조
  문제: 5개 기업 분석 중 1번 기업 내용 찾으려면 스크롤 30번
  솔루션: 주제 클릭으로 즉시 이동

자료 업로드 제한
  문제: ChatGPT 20개, DeepSeek 50개
  솔루션: RAG로 무제한 (400개 경험)

단일 관점
  문제: AI가 하나의 관점만 제공
  솔루션: 페르소나 모드 (다중 전문가)

사고 과정 휘발
  문제: 대화 종료 시 사고 과정 사라짐
  솔루션: 트리 구조로 영구 보존


[기존 시장 및 경쟁 제품과의 차별성, 주요특성, 장점 등]

차별성:

1. 패러다임의 차이
   경쟁사: AI = 비서 (일을 시킴)
   우리: AI = 사고 도구 (함께 생각함)

2. vs ChatGPT / DeepSeek / 두바오
   경쟁사: 선형 대화 (스크롤 지옥), 자료 20~50개 제한
   우리: 트리 구조 (클릭 이동), RAG로 무제한 자료

3. vs Manus (메타 인수)
   Manus: 동기식 → 비동기식 다단계 작업
   우리: 선형 → 트리 구조 사고 시각화

4. vs Notion AI
   Notion: 문서 내 단발성 대화
   우리: 트리 구조 영구 관리, 크로스노드 참조

주요 특성:

1. 사고 과정 시각화
   대화를 트리 구조로 표현, 사고 전개 과정 한눈에 파악

2. RAG 기반 무제한 자료
   한라대학교 400개 파일 학습 경험 기반 기술

3. 다중 관점 제공
   페르소나 모드로 여러 전문가 의견 동시 수집

4. 경로 전환
   잘못된 시점으로 돌아가 올바른 방향 재설정

5. 얼리어답터 검증
   GPT 출시 후 4년간 AI를 깊게 사용한 사용자들이 느낀 문제 해결

장점:

1. 생산성 향상
   - 스크롤 30번 → 클릭 1번 (검색 시간 97% 단축)
   - 무제한 자료 업로드 (100개 기업 동시 분석 가능)

2. 사고 품질 향상
   - 여러 경로 동시 탐색 → 더 나은 의사결정
   - 다중 관점 → 사각지대 제거

3. 지식 축적
   - 대화 종료 후에도 사고 과정 보존
   - 트리 구조로 지식 체계화

4. 기술 경쟁력
   - 실제 RAG 시스템 구축 경험 (한라대학교)
   - CLI Phase 완료 (109 tests, 84% coverage)
   - UI 프로토타입 구현 완료


[신규 아이템일 경우의 창의성 및 독창성]

창의성:

1. 패러다임 전환
   기존: AI에게 일을 시킨다 (비서)
   신규: AI와 함께 생각한다 (사고 도구)
   핵심 통찰: "다른 기업들이 AI를 비서로 대하면서 발생하는 문제들을 계속 발굴하고 해결"

2. 사고 과정의 시각화
   기존: 대화 히스토리만 쌓임 (선형, 휘발성)
   신규: 트리 구조로 사고 전개 과정 표현
   효과: 내가 어떻게 사고를 전개했는지 한눈에 파악

3. RAG 기반 무제한 자료 처리
   기존: AI의 문맥 이해 용량 한계 (20~50개)
   신규: 실제 구축 경험 기반 기술 (400개 파일)
   차별점: 이론이 아닌 실제 구현 경험

독창성:

1. 얼리어답터 인사이트
   창업자가 4년간 AI를 깊게 사용한 얼리어답터
   학교 AI 도입 프로젝트 주도 (한라대학교 RAG 시스템)
   실제 문제 경험 → 실제 솔루션 개발

2. 트리 구조 대화의 UX
   기존: 선형 대화에서 벗어나지 못함
   우리: 노드 클릭 → 경로 전환 → 사고 분기
   비유: 파일 시스템의 cd 명령어처럼 직관적

3. 페르소나 모드
   기존: AI가 하나의 관점만 제공
   우리: 한 질문에 여러 전문가가 각자 답변
   시각화: 전문가별 색상 구분 말풍선

4. 타이밍
   시장 타이밍: 5년이 지난 지금, 얼리어답터가 느낀 불편함을 일반 사용자도 느끼는 시점
   기술 타이밍: Manus의 메타 인수 (2026) = 시장 검증 완료


[중국 시장 진출 관련 전략 및 계획]

[시장에서 타겟 고객, 경쟁분석, 마케팅전략 등]

타겟 고객:

1차 타겟: 얼리어답터
  - GPT 출시 후 4년간 AI를 깊게 사용한 사용자
  - 이미 채팅 방식의 불편함 체감 중
  - 더 나은 도구를 찾고 있음
  - 페인 포인트: 스크롤 지옥, 자료 제한, 사고 과정 휘발

2차 타겟: 일반 사용자
  - 5년이 지난 지금, 얼리어답터가 느낀 불편함을 이제 느끼는 시점
  - 아직 느끼지 못한 분들도 곧 느끼게 될 것

주요 직군:
  1. 투자 분석가 / 컨설턴트 (여러 기업/시나리오 동시 분석)
  2. 연구자 / 작가 (브레인스토밍, 사고 과정 보존)
  3. 의사결정자 (선택지별 결과 탐색)
  4. 교육자 (학생별 맞춤형 경로)

경쟁 분석:

ChatGPT
  강점: 시장 1위, 브랜드 파워
  약점: 선형 대화, 자료 20개 제한
  우리 대응: 트리 구조 + RAG 무제한

DeepSeek
  강점: 자체 LLM, 50개 파일
  약점: 여전히 선형, 중국 중심
  우리 대응: 사고 시각화 + 글로벌

Notion AI
  강점: 문서 통합
  약점: 단발성 대화, 트리 없음
  우리 대응: 트리 구조 영구 관리

Manus
  강점: 메타 인수 (검증)
  약점: 서비스 종료
  우리 대응: 시장 공백 메우기

"GPT 출시 후 4년 동안 AI를 깊게 사용하면서 채팅 방식의 한계를 절실히 느꼈습니다.

하지만 더 큰 문제는 '선형적 대화 구조'였습니다. 5개 기업을 분석하다가 1번 기업 내용을 찾으려면 스크롤을 30번 이상 올려야 했습니다.

이 순간, 깨달았습니다. AI를 '비서'로 대하는 패러다임 자체가 문제라는 것을.

AI는 일을 시키는 도구가 아니라, 내 머릿속 생각을 시각화하고 발전시켜주는 도구여야 합니다.

다른 기업들이 AI를 비서로 대하면서 발생하는 문제들을 계속 발굴하고 해결하는 서비스를 만들고자 창업을 결심했습니다."
